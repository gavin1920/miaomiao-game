品牌 · Brand

第一原则:可爱。任何取舍与可爱冲突时,可爱优先
STORY

喵都幸存者 Meow Survivors 是猫主题的幸存者 like 小游戏:夜幕下的喵都,夜巡队长「大橘」独自面对无尽鼠潮。 像素重制方向的风格代号是「奶油团子」——头即全部、一切皆圆、豆眼里装着双高光; v2.2 起 UI 层升级为「可爱像素」:圆角身板 + 像素骨感,直角一律消灭,详见章节「界面」。

四个性格关键词

团

团子感

头即全部:头宽 ≈ 身宽 ×1.35,头高占全身 55~60%。轮廓禁止尖角,像素角落一律内收 1px。

眼

豆眼是灵魂

圆角大豆眼,双眼宽 ≥ 脸宽 40%,双高光:左上主高光 + 右侧次高光。眼睛色全游戏统一 #2a1e33。

奶油

奶油配色

低饱和暖色,主体亮、背景暗,扁平 2 阶上色。阴影只许在下颌底、身体底缘、耳后侧。

夜

夜色喵都

背景深冷(#2e2a3c 系)、光源暖亮:灯箱、霓虹、摊位,全部可爱化,不做恐怖感。

语气规范(用游戏里真实写好的话)

✓ 这样说话

短句 + 叹号 + 叠词,像朋友喊你上场:
「开始夜巡 !」「知道啦!」「开心收下!」「再来一局!」
失败不指责玩家:「大橘累倒了…」——把疲惫留给猫,把鼓励留给下一局。

✗ 不这样说话

不讽刺、不垃圾话、不用烂梗;不写「你死了」「菜就多练」;不堆营销词。 敌人也可爱:一切「凶」元素(牙/眉/爪)最小化表达,圆形 + 腮红不变。

M3 起为游戏唯一 UI 字体:本手册整页文字(含本段)内嵌的就是像素副本实机同款 zh_hans woff2,所见即游戏所得。原生网格 12px,笔画对齐像素;数字/计分/色号同字体。

理想字号 = 12 的倍数(12/24/48);游戏实机允许 12~24px 间按需缩放 (14.5/17/22 均有使用),大标题与海报优先取整数倍。

✓ 字的规则

标题投影只用硬偏移(如 2px 2px 0 / 4px 4px 0),不加模糊发光;英文副标字距 4~8px; 数字/计分/倒计时与正文同一套像素字。

✗ 字的禁令

UI 只此一种字体,不混第二显示字体;不许斜体; 字体加载失败必须兜底可读;正文避免 12px 以下(像素发虚)。

04

画风 · Pixel Style

奶油团子七条硬规则:评审一票否决项
RULES

R1 唯一描边色

全游戏只有 #453244(暖梅棕)1px 描边。禁止黑色、禁止其他任何描边色。

R2 干净像素

角色禁止抗锯齿像素、孤点杂点、半透明过渡。要过渡,用 1px 锯齿排线,不用柔化。

R3 扁平 2 阶

角色只画底色+阴影两阶;阴影只出现在下颌底、身体底缘、耳后侧三处。

R4 有脸必有三件

眼(含双高光)+ 腮红 + ω 嘴,缺一不可。无脸物除外:宝石/金币/砖块。

R5 眼睛统一

眼睛 #2a1e33、高光 #ffffff,全游戏统一,任何角色不许换眼色(煤球金瞳走特批)。

R6 抖动只属于地图

地面/建筑 tile 允许 2~3 阶 + 受控棋盘抖动;角色禁止抖动。

R7 整数像素动

动效位移全部整数像素;squash & stretch 幅度 ≤ ±1px/级,只用于冲刺/入场/死亡。

🐾 渲染基准

网格 ×2 = 绘制单位,2K/100% 下 1 网格像素 = 1 屏幕像素;渲染必须 imageSmoothingEnabled=false / image-rendering:pixelated。

缩放:对与错(用大橘真身演示)

守则 · Do & Don't
