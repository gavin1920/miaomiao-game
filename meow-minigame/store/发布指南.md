## 1. 先确认账号类型：必须是「小游戏」，不是「小程序」

微信把「游戏」归为独立账号类型。**小程序账号里没有游戏类目，发不了游戏**；你在"小程序开发与发布流程"页面看到的流程框架和它是通的，但注册入口要选「小游戏」。

- 已有小游戏账号（mp.weixin.qq.com 登录后左上角账号类型显示"小游戏"）→ 直接进第 2 步。
- 只有小程序账号 → 用**另一个未绑定公众平台的邮箱**重新注册，账号类型选 **小游戏**，主体选 **个人**（个人可注册小游戏，只是不能开虚拟支付/内购——本游戏无内购，正好）。
- 注册完成后，在 **设置 → 基本设置** 里能看到 **AppID**，后面要用。

> 同一邮箱只能注册一个账号；个人主体注册数量有限额，够用。

## 3. 备案与游戏资质（审核前的一次性门槛，越早启动越好）

按官方当前要求（2025-2026 口径，以页面提示为准）：

1. **小程序备案**：公众平台 → 「小程序发布流程 / 小程序备案」按引导提交主体与负责人信息，通常 1~2 个工作日+平台审核。**不备案无法发布。**
2. **游戏资质（无内购路径）**：备案流程中选择游戏情况后进入「资质提交」，免费无内购小游戏需要：
   - **《计算机软件著作权登记证书》** 或 **《电子版权认证》** 二选一；
     - 软著：中国版权保护中心或各省版权局代办，周期数周到数月，**建议今天就启动**；
     - 电子版权认证：约 10~15 个工作日，可加急（第三方服务）。
   - 部分「纯中文游戏名 + 无虚拟支付 + 无上线风险内容」的情形支持**承诺制/免软著**通道，提交前先在资质页面试试选"无版号、无内购、暂无软著"，看页面是否放行——放行就省掉软著等待。
   - **《开发者承诺函》**：官方模板下载、签字（个人签名即可）后上传。
3. **健康系统/防沉迷**：平台托管。后台如有「健康系统协议」签署入口，签掉即可，无需开发。
4. **用户隐私保护指引**：后台「设置 → 服务内容声明 → 用户隐私保护指引」中如实声明。本游戏**不调用 wx.login、不获取用户信息、无位置、无相册读取**（"保存战报"是写入相册，若提审表单问及，按"向用户写入相册"勾选声明）；本地存档仅存最佳纪录等游戏数据。声明越少越快过。

> iOS 虚拟支付被禁、安卓虚拟支付要版号——本游戏**无内购**，这些都不碰，上线最顺。

## 6. 提交审核 → 发布

1. 版本管理 → 开发版本 → 「提交审核」。
2. 表单要点：
   - 版本号 **1.0.2**（与最近一次 upload 的版本号一致）；
   - **版本描述**直接用 §8 的文案；
   - 类目核对：休闲游戏；页面若要求功能演示/截图，用 `store/raw-combat.png`、`raw-menu.png`、`raw-result.png`（1280×720 横屏实机图）；
   - 测试说明：**无需账号、无后端**，进入点「开始夜巡」即可游玩，全功能单机本地完成。
3. 等待审核（小游戏一般几小时~几天）。被驳回按 §9 对策处理后重新提审。
4. 过审 → 版本管理 → 审核版本 → 「全量发布」。发布后即可在微信内搜索名称/扫码使用。

## 7. 以后怎么改版本（双端同步纪律）

网页版（`miaomiao-deploy/`）永远是唯一引擎源头：

```bash
# 改完网页版 js/ 后，一条命令重出小游戏包：
bash C:\Users\gavin\Desktop\Games\miaomiao-deploy\tools\sync-minigame.sh
```

- 脚本会重跑 `tools_transform.py`（网页版 main.js → 小游戏 fork）并重拼 `bundle.js`，锚点失配会报错而不是静默出错——报错时按提示更新 transform 里的锚点。
- 改了 UI 结构（新增面板/按钮）才需要动 `meow-minigame/src/ui.js` 和 transform。
- 本地快速回归：浏览器打开 `meow-minigame/test/bundle.html`（带调试钩子）；加 `?nodev=1` 隐藏 dev 面板出截图。
- 发新版：改版本号（§6 重跑 upload），并在游戏内「更新日志」（changelog.js）加一条。

## 9. 常见驳回点与对策

| 驳回点 | 对策 |
|---|---|
| 类目/资质不符 | 确认账号是「小游戏」且类目为休闲游戏；资质按 §3 补齐 |
| 权属存疑 | 提交软著/电子版权认证，或走承诺制；CREDITS.md 证明采样授权 |
| 名称侵权/含误导 | 换 §2 备选名；介绍中不提任何现有商业游戏 |
| 诱导分享/支付违规 | 本游戏无此类功能；若未来加激励视频广告，先读官方广告规范 |
| 内容不适格 | 战斗均为卡通猫鼠，无血腥；若有截图要求，用 store/ 实机图 |
| 真机崩溃 | 用体验版先在 iOS/安卓各测一台；崩溃日志在后台「运维中心」 |
