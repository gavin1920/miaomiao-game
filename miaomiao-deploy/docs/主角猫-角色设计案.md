# 喵都主角猫 · 角色设计案 v1（仅设计 · 未实现）

> 定位：为《喵都幸存者》引入可选主角。当前只有大橘一只；本方案新增 7 只各有
> 背景故事与独有特性的主角猫。**本阶段仅设计：不改代码、不改数值表。**
>
> 平衡底线：每只猫的独有特性价值 ≈ 1 个被动道具（约 1.5~3 级同类被动的量），
> 有得有失；不新增成长倍率轴、不吃猫爪印的指数叠层、不绕过引擎底线；
> 动态难度三根轴（压力 / DPS / 生存）继续吸收一切清场与输出差异；
> run 终点（敌人伤害轴永不封顶的「那一击」）与老鼠妈妈全屏斩机制保真。
>
> 数值哲学：沿用 game_config.js 的「唯一数值表」约定——实现时所有特性数值
> 进配置表 `characters` 块，游戏内 ⚙ 面板可预览可调。

---

## 1. 设计护栏（为什么不会破坏平衡）

| # | 护栏 | 说明 |
| --- | --- | --- |
| 1 | 同一基准模板 | 所有猫共用 player 基础：100 HP / 172 移速 / 55 拾取 / 0.55s 受击无敌。差异**只**来自 1 个独有特性；大橘 = 无特性基准 |
| 2 | 一猫一特性，预算 ≈ 1 个被动道具 | 对照锚点：牛奶盒 1 级 = +15% 血 + 0.5/秒回复；锦鲤 1 级 = 幸运 +0.15；猫薄荷 1 级 = 伤害 +10%。任何特性不超过「牛奶盒 2 级」级别的量 |
| 3 | 不新增成长通道 | 特性只挂在现有结算点上（maxHp / regen / 移速 / 受击结算 / 条件伤害修正 / 初始武器 / 免死）。伏特的反震伤害明确**不吃**猫薄荷、锐爪印、暴击、吸血等一切加成，杜绝「故意挨打」的叠层收益 |
| 4 | 动态难度是天然天平 | DPS 轴（parBossTTK=15s 恒温）吸收捕头的对鼠增伤；压力轴（清场越快下轮越难）吸收一切清场加速；生存轴（血线常年红 → 下轮伤害喘息）自动回应免死/厚血流，无需额外配平 |
| 5 | Run 终点保真 | 煤球的九命符只把「那一击」推迟到下一次，不取消；敌人伤害轴永不封顶，run 仍有终点 |
| 6 | 老鼠妈妈机制保真 | 全屏斩无视一切免死 / 无敌 / 冲刺无敌帧（本就保底 1 点不致死，不消耗九命符）。她是结算 Boss（核心指标 = 击杀用时），**所有角色对她的基线一致**：捕头的鼠类增伤不含她 |
| 7 | 每个特性自带「过强旋钮」 | 验收实测若超标，按各猫小节的旋钮数值回调即可，不需要重新设计 |

## 3. 大橘（daju）—— 夜巡队长（基准，已有角色）

**故事**：喵都夜巡队最后的在编队员。白天睡在夜市烤鱼摊的空鱼箱里，晚上沿着摊
位巡逻一圈，把偷吃的老鼠赶回下水道。队里其他猫早就「退休」进了各家的暖气房，
只有他还守着这条街——毕竟夜市的大爷们，人人都会给他留半条烤秋刀鱼。

**特性**：无。他是一切平衡的锚点：其他 7 只猫的任何特性，对照的都是他。

## 4. 雪宝（xuebao）—— 汤屋看板娘

**外观**：白色长毛猫，尾巴尖一点淡蓝，脖子上搭一条温泉毛巾，胡子尖结着小霜花。

**故事**：雪山温泉「汤屋」的招牌猫。客人说泡汤前摸摸她的头，温泉就不容易凉。
她睡在更衣室的藤篮里，毛厚得像一床被子，小孩子抢着抱。有一年夜里有黄鼠狼翻墙
进来偷浴巾，她从藤篮里起来、抖了抖毛——第二天墙上多了一道狼形的雪印。

**特性「厚绒毛」（被动）**：

| 项目 | 数值 | 说明 |
| --- | --- | --- |
| 最大生命 | +25%（100 → 125） | 牛奶盒的 hpMult 乘在 125 之上 |
| 自带回复 | +0.3/秒 | 走 mods.regen 通道，与牛奶盒加法叠加 |
| 移速 | −5%（172 → 164） | 厚毛太热的代价 |

**强度对照**：≈ 牛奶盒 1.5 级 − 5% 移速。纯生存手感，零输出增益。
**过强旋钮**：回复 0.3 → 0.2；或移速 −5% → −8%。

## 5. 咪酱（mijiang）—— 外卖店跑腿王

**外观**：曼基康矮脚猫，奶黄色配白肚皮，背着一只迷你外卖箱，跑起来像毛球滚。

**故事**：无尽街区「午夜外卖」的编外员工。腿短，但步频快得看不见影子，店里
的规矩是「超时免单」——自从她上岗，老板再没免过单。街区流传一个传说：凌晨
三点之后，你能看见一只矮脚猫贴地飞行。她本人对此的回应是：喵。

**特性「小短腿·大步频」（被动）**：

| 项目 | 数值 | 说明 |
| --- | --- | --- |
| 移速 | +8%（172 → 186） | 游戏当前没有玩家移速类被动（小铃铛是弹速），+8% ≈ 70 级自动成长 8 级的量 |
| 最大生命 | −15%（100 → 85） | 85 血 ≈ 中后期挨两下就没，走位就是她的血条 |

**强度对照**：机动换容错的标准 sidegrade。注意大白鹅的 lunge、鼠王的蓄力冲锋
（3.4× 速度）依然必须预判，跑得快 ≠ 无敌；186 也追不上任何成长后的怪群合围，
只提升转场与脱身质量。
**过强旋钮**：+8% → +6%（181）；或生命 −15% → −20%（80）。

## 6. 捕头（putou）—— 码头捕鼠世家第 13 代传人

**外观**：狸花短毛猫，虎斑纹路清晰，左耳一个旧豁口，腰上系半张渔网当腰带。

**故事**：港湾码头仓管世家的家猫，祖上 12 代都在货船上看仓，家训只有八个字：
「仓中有粮，猫爪不软」。他认路认秤更认鼠——闻一下麻袋就能报出里面蹲了几只。
码头小哥说他抓鼠从来只抓三下：一下警告，一下定罪，第三下不用看。

**特性「祖传捕鼠心得」（被动 · 条件增伤）**：

| 目标 | 修正 | 范围 |
| --- | --- | --- |
| 鼠类 | 伤害 ×1.2 | 灰灰鼠（含精英个体）、鼠王·铁须、鼠王召唤鼠 |
| 飞羽类 | 伤害 ×0.9 | 小麻雀、蝙蝠仔、鸽子咕咕 |
| 其余 | 无修正 | 蜗牛仔 / 大白鹅 / 浣熊团子 / 斗牛犬 / 三花姐 / 老鼠妈妈 |

**平衡要点**：
- 老鼠妈妈是结算 Boss，明确**不吃**该加成（护栏 6：全猫对她的击杀用时基线一致）。
- 对鼠王 +20% 会被 DPS 轴恒温部分回收（打得快 → 下轮头目/鼠王追血）。
- 波次表自带曲线：5 分钟起蝙蝠权重上升、8 分钟起斗牛犬登场 → 前期顺风，
  中后期回归平庸，不需要人为压制。
- 修正乘在全局 might 乘区之外的独立一层；命中后的暴击 / 吸血结算照常生效。

**强度对照**：条件版的猫薄荷 2 级（+20%），代价是三系常见怪 −10%。
**过强旋钮**：×1.2 → ×1.15；或飞羽 ×0.9 → ×0.85。

## 7. 茉莉（moli）—— 樱花茶馆驻唱

**外观**：暹罗猫，奶油身体配深棕重点色（脸 / 耳 / 尾 / 四爪），蓝眼睛，脖颈一条小丝巾。

**故事**：樱花公园茶馆的驻唱。每天黄昏开嗓，一开口整条樱花道都安静下来——
不是好听的，是嗓门大。茶客们嘴上嫌吵，身体很诚实：她巡演（在每桌睡一觉）的
日子，茶馆流水翻倍。她的喵喵音波是自学的，师傅是公园里那只抢了她小鱼干的乌鸦。

**特性「金嗓子」（被动 · 初始武器差异）**：

| 项目 | 内容 |
| --- | --- |
| 初始武器 | 喵喵音波 Lv1（**不**自带猫爪连击） |
| 幸运 | +0.3（≈ 锦鲤 2 级；配菜，走现有 luck 通道：宝箱 3/5 件概率、金币经验档位、杂兵宝箱概率） |
| 武器上限 | 不变：免费位 = 音波，猫爪连击变成她可在三选一里自选的武器，总持有仍 ≤ 5 把 |

**平衡要点**：
- Lv1 音波 vs Lv1 猫爪基本等价（音波 10 伤 / 1.1s / 自动索敌；爪 14 伤 / 1.3s /
  击退 130）——清群略弱、打散怪与走 A 更舒服，整体零和。
- 她的保底进化路线变成超声波（素材 = 小闹钟），进化总数与其他猫一致。
- 实现注意：`buildPool` 里「默认猫爪不计槽位」是硬编码（`w.id !== 'claw'`），
  需参数化为「每角色的免费武器位」。

**强度对照**：起点差异 ≈ 零和；幸运 +0.3 是甜点不是主菜。
**过强旋钮**：若实测前期偏弱 → 给 Lv1 音波临时 +1 发（仅 1 级数值）；若偏强 → 去掉幸运 +0.3。

## 8. 煤球（meiqiu）—— 游乐园守夜猫

**外观**：纯黑短毛猫，胸口一撮白毛，眼睛金黄。美术梗：夜景里只画一双眼睛+白毛。

**故事**：幽灵游乐园唯一的正式员工（没有工资那种）。摩天轮停转之后，园里只剩
她一个，负责每晚绕场一圈——鬼不怕她，她也不怕鬼，双方保持职业性互不搭理。
园区的传说之一：煤球攒着九条命，前八条都存在摩天轮顶端的信号箱里。她从不否认。

**特性「九命符」（被动 · 免死）**：

| 项目 | 数值 |
| --- | --- |
| 触发 | 受到**致死一击**时改为保留 1 点体力（`P.hp<=0 → startDying()` 之前拦截） |
| 触发后 | 无敌 1.2 秒，画面提示「第九条命还给你」 |
| 次数 | 每轮限 1 次；进入新一轮时重置 |

**平衡要点**：
- 老鼠妈妈全屏斩本就保底 1 点不致死 → **不消耗**九命符，与结算 Boss 零交互。
- 纯保险，零输出。动态难度生存轴看到的是「血线常年红」，会自动给出下轮伤害
  喘息——等于系统自带制衡，无需额外配平。
- 后期敌人伤害轴永不封顶，一轮照样可能死 2~3 次：九命符改变死亡的时间点，
  不取消 run 的终点（护栏 5）。

**强度对照**：约等于每 10~15 分钟 1 次复活，价值集中在开荒高轮次。
**过强旋钮**：改为「每 2 轮 1 次」；若过弱 → 无敌 1.2s → 1.5s。

## 9. 蹦蹦（bengbeng）—— 烤鱼摊编外学徒

**外观**：黑白奶牛猫，斑纹歪歪扭扭（奶牛猫标配），尾巴永远翘成问号。

**故事**：老城夜市烤鱼摊的「编外学徒」——摊主没同意，她自己入职的。每天蹲在
烤架后面偷师翻鱼，久而久之练出一身横冲直撞的身法：钻桌底、翻鱼箱、从大爷
裤裆底下三步上篮。夜市摊主的共识：鱼少了一条不可怕，可怕的是听见「哐当」。

**特性「疯猫冲刺」（主动技 · 全游戏首个主动键）**：

| 项目 | 数值 |
| --- | --- |
| 操作 | PC：空格；手机：屏幕右下角新增技能按钮（带 CD 圈） |
| 行为 | 向当前移动方向冲刺（无输入时朝面向方向）：位移 180px / 0.35 秒 |
| 无敌 | 冲刺**前 0.25 秒**无敌（穿过怪群用） |
| 冷却 | 6 秒 |
| 伤害 | **0**。不造成伤害、不击退，纯位移 |

**平衡要点**：
- 新增输入面（键盘 + 触屏按钮 + 从摇杆取方向），是唯一的新 UI 面。
- 与受击无敌帧（0.55s）独立计时，互不覆盖。
- **老鼠妈妈全屏斩无视冲刺无敌帧**（护栏 6：红圈收缩照样结算，冲刺救不了）。
- 可用它侧闪鼠王蓄力冲锋——但冲锋速度 3.4× = 231px/s > 冲刺位移，只能侧向
  让身位，不能直线比快，技巧上限高但不无脑。
- 6 秒 CD + 180px 距离（≈ 1 秒走路量）锁死收益上限：高手省血，新手按了白按。

**强度对照**：纯操作技巧型，无任何数值增益。
**过强旋钮**：CD 6 → 8 秒；或无敌 0.25 → 0.15 秒。

## 10. 伏特（fute）—— 霓虹灯箱电工猫

**外观**：斯芬克斯无毛猫，粉灰皮肤，大耳朵，常年背一个巴掌大的工具包。

**故事**：出生在老城夜市霓虹灯箱后面，从小舔灯箱电线当早餐，毛发因此……好吧，
兽医说无毛和吃电线没关系，她不信。她负责整个夜市的「照明安全」：哪家的灯箱
接触不良、哪串彩灯半夜闪，都是她一爪子拍好的。收据是：一根小鱼干 / 灯 / 夜。

**特性「炸毛静电」（被动 · 受击反震）**：

| 项目 | 数值 |
| --- | --- |
| 触发 | 被**实际命中**时（受击结算处；无敌帧内的重复碰撞不触发；每次受击至多一次） |
| 效果 | 以自身为中心 100px 内所有敌人受到 (15 + 2 × 当前等级) 点伤害，并击退（力度 150，与猫爪 130 一档） |
| 加成 | **固定公式，不吃**猫薄荷 / 锐爪印 / 暴击 / 吸血等一切加成（防「故意挨打」叠层） |
| 击退 | 照常结算 mass / kbRes（斗牛犬 0.35 基本推不动） |

**平衡要点**：
- 自我补偿型：被围时它是救急群伤；躲得好它就是白板。它奖励的是「失误之后
  仍能脱身」，不是「故意挨打换输出」（公式不吃加成 + 单次触发已双重锁死）。
- 1 级时 ≈ 17 点/次（约一次 Lv1 猫爪），价值集中在前 10 分钟与被围救场；
  50 级 115 点在中后期怪物血量面前可忽略，**不参与长线膨胀**。

**过强旋钮**：(15 + 2×lv) → (10 + 1.5×lv)；或半径 100 → 80。
