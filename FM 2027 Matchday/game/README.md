# FM 2027 Matchday · 英超梦幻对决（可玩版）

**双击 `index.html` 即可游玩**（纯离线单页应用，无需安装/联网/构建；推荐 Chrome / Edge）。

## 玩法流程

1. **开局**：选择预算档位（€4.5亿 / €6亿 / €8亿）与队名
2. **转会市场**：用固定预算在英超 20 队全部球员池中签约（16-23 人，位置结构达标）
   - 身价采用 **德转 Transfermarkt 参考身价（2025 夏窗后口径）**
   - 你签走的球员会**从原俱乐部除名**——挖空对手也是一种战术（锋线被挖空的对手会自动收缩）
   - **球探推荐阵容**：一键按位置需求+性价比组出 18 人框架，可再微调
3. **选择对手**：20 支英超球队任选单场邀请赛（你主场），显示阵容强度/风格/难度；或开启赛季——
   **🏆 10 轮迷你赛季** 或 **🌍 完整赛季（42 个比赛周双循环：每队 40 战 + 2 轮空，有主客场与轮空周）**，
   20 队积分榜 + 更衣室新闻墙 + 射手榜 + 伤病名单，完赛自动存档
4. **首发阵型**：21 套阵型模板 + 自动排兵（换阵型会智能迁移已有排布），替补席可自选（≤9 人）；
   赛季模式带**伤病名单**（伤退缺阵 1-3 轮）与**体能延续**（不轮换的球员越踢越累）
5. **战术板**（核心）：
   - **自由拖拽站位**：11 个位置可任意摆放，真正自定义阵型
   - **30 个位置角色** × 3 档职责（职责影响该球员攻防投入与角色收益）
   - **双轴心态**：攻压（全力防守→全力进攻）× 防稳（极不设防→铁桶）独立调节——全攻有防线透支+体能代价，铁桶真实换防守稳固，双拉满会体系超载
   - **16 项球队指令**：传球风格、节奏、防线高度、逼抢强度/区域、攻防宽度、进攻侧重（打对手防守弱侧有真实收益）、边后卫套上、抢断强度（真实中断收益+牌险）、门将出球 + 快速反击/就地反抢（需逼抢支撑）/拖延时间/越位陷阱
   - 定位球主罚（角球/任意球/点球）与队长指派
   - **战术分析室**实时给出警告（如"高防线但中卫速度不足"）
   - 战术预设可保存/载入（localStorage）；**回市场/换阵型不再静默重置你的战术**
   - **🎲 比赛 Seed**（可选）：同 seed + 同阵容同战术 = 完全相同的比赛，发给朋友公平对决
6. **比赛日**：分钟级引擎仿真 + 球场实时动画（射门/进球有飞行轨迹与闪光演出，球员点显示姓名）+ 中文解说 + 实时换人（**5 名额 + 3 窗口**，半场换人不占窗口）与临场战术热调整；AI 教练也会追分、收缩、拖延；**⚡ 智能节奏**（无事件快进、事件放慢，可关；空格暂停、1/2/3/4 倍速、S 智能节奏）；**🎙 解说人格**（火焰/数据大师/绿茵诗人/关闭）；**比赛中刷新可续打**（seed+动作日志确定性重放）
   - **🧨 挖空恩怨**：从某队挖走 ≥2 人，再遇他们时逼抢/抢断/心态会被怒气强化——挖空对手有代价
7. **复盘**：完整技术统计、球员评分（含全场最佳庆祝）、**比赛时间轴**（进球/红黄牌/换人/伤退按分钟定位）、**战术归因报告**（高位防线被打穿几次、传中缺抢点、反抢战果、体能崩盘等）、Seed 一键复制

## 战术真的有用（引擎约束）

- **双轴心态是核心权衡**：攻压拉满进攻显著变强，但防线透支+体能加速崩；防稳拉满真实封堵机会，压上对手会打你身后——不存在无脑最优解
- 防线高度 vs 对手锋线速度：高位防线会被身后球与反击惩罚（含越位陷阱风险）
- 逼抢/逼抢区域真实干扰对手出球并降低其机会质量，但加速体能衰减（75 分钟后现形）；凶狠抢断有真实中断收益，代价是牌与点球风险；就地反抢需要逼抢强度支撑
- 传球风格进入控球公式（传控队真控球）；门将长传直供给应但更容易被打反击；慢节奏省体但让出比赛主动权
- 传中战术需要支点/抢点型目标，无锋阵传中质量会被打折；进攻侧重打对手防守弱侧有真实收益，打强侧为负
- 角色组合有联动加成：翼卫套上+边锋、伪九号+前腰后插上、支点+抢点、出球中卫+组织后腰
- 位置不适配会按比例折损球员发挥（天然位置 100% / 客串 ~90% / 勉强 78%）；红牌有真实减员惩罚
- 领先方 75 分钟后自动收缩（"park the bus"），落后方末段搏命但身后留空——补时绝杀由此而生，补时 5-11 分钟随犯规/进球浮动

## 数据说明

- 俱乐部与阵容：2025-26 赛季英超 20 队一线队（337 人）
- 身价：德转 transfermarkt 参考身价（€M，2025 夏窗后），仅供娱乐
- 属性：引擎用 0-100 标度（速度/射门/传球/盘带/防守/身体 + 门将四维），为可玩性做过标定
- 引擎基线（400 场官方战术批测，对照 data/calibration/epl_baseline.csv）：场均总进球 ~2.7、射门 ~9.5/队、传球成功率 ~81%、黄牌 ~4/场、红牌 ~0.2/场、主胜 ~45%、绝平/绝杀由末段戏剧引擎自然产生

## 与仓库其他部分的关系

`docs/`、`data/`、`simcore/`、`schemas/` 是本项目早期的设计文档与 Python 仿真原型（含部分过时的俱乐部名单与占位阵容）。本目录 `game/` 是面向玩家的自包含可玩版本，战术词汇（角色/指令/阵型）沿用其设计语言并做了扩充。`reviews/` 是三方评审（玩家/球迷/专家）的多轮评审记录与共识文件。
