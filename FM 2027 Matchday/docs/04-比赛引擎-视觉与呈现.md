# 04 · 比赛引擎 · 视觉与呈现（Presentation Layer）

## 目标与基线

**"FM26 的画面是系列最大进步，但离 FIFA 还差一个转播级呈现的距离；我们用工程手段补上这个距离。"**

| 基线 | 现状 | 我们的差距点 |
|---|---|---|
| FM26 ME | Unity 重建后动画更流畅、有"比赛叙事感"，但仍被批生硬、可预测、球脚分离 | 动画与球的同步、镜头语言、图文包装 |
| FIFA/FC26 | 画面天花板（动捕+HyperMotion 级流程） | 战术深度/AI 拟真（不在此层解决） |

关键认知：**观感 = 画面素质 × 镜头语言 × 图文包装 × 音频。** FIFA 观感的一半来自转播包装（机位切换、回放、数据图版），这是工程问题而非美术预算问题——单联赛单球场的规模下，小团队可以打赢。

## 技术选型

- **Unity 6 + URP**（推荐）：足球动画/球场/人群资产生态最全；C# 与仿真核同语言，状态流零成本接入；FM26 同引擎，证明天花板够用。
- Unreal 5 备选：若团队有 3D 专才，画面上限更高（Lumen/Nanite + MetaHuman），代价是迭代速度与动画管线成本。
- 仿真核保持引擎无关（独立程序集），呈现层只是它的一个消费者——**呈现层永远可以被替换**（这也是将来做"纯精华回放"模式、掌机版的基础）。

## 渲染结构

```
仿真核 25Hz 状态流 ──▶ 帧间插值(50–60fps) ──▶ 场景驱动
                                        ├─ 球员：位置/朝向/速度/动作状态 → 动画控制器
                                        ├─ 球：轨迹 → 球渲染（自旋可视化）
                                        ├─ 事件队列 → 转播导演 + 特效/音频触发
                                        └─ 遥测 → UI 图版
```

## 动画系统（成败关键，FM 的最大失分点在这里）

1. **运动基础**：Motion Matching 或高质量混合树，基于足球动捕库（跑/加速/减速/侧滑步/急停变向/对抗/倒地/起跳）。可采购商业足球动捕包 + 资产商店资源起步，预算允许后自采。
2. **球-脚同步（与 FM 拉开差距的第一优先级）**：触球时刻由仿真核精确给出（含触球点、球速），渲染层做两件事——在触球窗口内**选择接触类动画并用 IK 把支撑脚/摆腿贴到球的实际位置**；触球后球按物理飞行。不允许出现 FM 式"球和脚各走各的"。
3. **动作-事件映射**：每个仿真事件类型映射到一个动画变体池（抢断=捅球/铲球×3；射门=正脚背/推射/捅射…），由属性决定变体概率：Finishing 高→更多正脚背抽射；Flair 高→解锁花式过人变体。变体池与属性调制参数见 [data/presentation/animation_map.json](../data/presentation/animation_map.json)。
4. **个体差异层**（让 500 名球员"不像复制人"）：
   - Pace/Acceleration → 步幅与步频参数化；
   - 身高体重 → 骨骼缩放 + 重心补偿；
   - 签名动作池（v2）：为少数球星配专属庆祝/标志性动作。
5. **门将动画集**：扑救按方向×高度×速度分型（近角反射、远角飞身、单刀封堵），由仿真事件参数驱动，不做"万能扑救动画"。

## 转播导演（Broadcast Director）——观感的另一半

一个状态机驱动的"自动导播"，消费事件流切换机位（状态机配置：[data/presentation/camera_director.json](../data/presentation/camera_director.json)）：

| 场景 | 机位策略 |
|---|---|
| 默认/中场倒脚 | 高位战术广角（能看清阵型——战术玩家的需求） |
| 推进进入前场 1/3 | 侧向追踪镜头，视角放低，速度感 ↑ |
| 禁区机会 | 近景低机位，慢动作候选 |
| 死球（界外球/任意球） | 站位特写 → 罚球者特写 |
| 进球 | 进球瞬间 → 3 机位回放（全景/低机位/射手特写）+ 慢镜 |
| 半场/全场 | 数据图版序列（见下） |
| 平淡期 ≥3 分钟 | 教练席/球迷/球员特写切镜（用 AI 经理的决策理由做字幕素材） |

- 防眩晕规则：最小镜头停留 8s，切换硬切+短黑场，不做漂移式运镜。
- 玩家可锁定单机位（战术视角 = FM 用户的舒适区）。

## 图文包装（Graphics Package）

- 转播级比分条（队徽、比分、时间），进球/红牌弹图。
- 实时数据条：控球率、射门数（导演在平淡期切出）。
- 半场/全场图版序列：xG 曲线、射门落点图、传球网络、两名球员热图对比、AI 经理换人时间线（附决策理由）。
- 全部数据来自仿真遥测，天然真实。面板目录与触发配置见 [data/presentation/graphics_panels.json](../data/presentation/graphics_panels.json)。

## 音频

（规则配置见 [data/presentation/audio_rules.json](../data/presentation/audio_rules.json)）

- **人群反应引擎**：紧张度模型（球进入禁区、连续传递、比分接近度）驱动人群音量/语气分层；进球=爆发层；紧张=低频嗡鸣。
- 触球声分型（传球/射门/封堵）、球网声、哨声、草皮摩擦。
- 队伍助威曲/队歌化氛围（化名球队原创音乐，规避版权）。
- 解说（v2）：模板+TTS 拼接，输入是仿真事件流 + AI 经理理由标签，能自然说出战术事件。

## 天气与氛围渲染

- 雨天：粒子雨 + 湿润草皮反射 + 球速视觉（与仿真天气参数联动）。
- 夜场：球场灯光系统 + 泛光；日场按下午光的镜头眩光。
- 看台：程序化人群（Instancing，数万级）+ 布旗/横幅按球队配色生成。

## 配置数据与事件契约

呈现层的所有"设计决定"都以配置数据落地（机器可读、可校验），代码只是执行器：

| 文件（data/presentation/） | 内容 |
|---|---|
| [camera_director.json](../data/presentation/camera_director.json) | 转播导演状态机：12 状态、enter/exit/priority、防眩晕规则 |
| [animation_map.json](../data/presentation/animation_map.json) | 动作/事件 → 动画变体池 + 属性调制（属性可视化）+ 门将扑救分型 + 个体差异层 |
| [graphics_panels.json](../data/presentation/graphics_panels.json) | 图文面板目录 + 半场/全场图版序列 + 数据来源（遥测事件） |
| [audio_rules.json](../data/presentation/audio_rules.json) | 紧张度模型 → 人群分层、触球声分型、定位球氛围 |

- **事件词表单一来源**：[schemas/telemetry_events.json](../schemas/telemetry_events.json)（22 个事件）——转播导演、图文、音频、动画与仿真遥测同源引用，不各造事件名。
- 呈现层消费的状态流结构：[schemas/state_stream.schema.json](../schemas/state_stream.schema.json)（动作 enum 与 animation_map 一致）。
- 校验：`python scripts/validate_tactics.py`（含"配置引用的事件 ⊆ 遥测词表"检查）。

## 性能预算

- 目标：中端 PC（GTX 1660 级）1080p60。
- 22 名高模球员 + LOD、程序化人群、单球场场景 → 完全可控；瓶颈预计在动画采样与 IK，需预算 profile。

## 与 FM26 / FIFA 的具体差异清单（对外宣传口径，对内验收表）

| # | 我们做到 | FM26 现状 |
|---|---|---|
| 1 | 球-脚同步（IK 贴球），触球时刻精确 | 常见球脚分离 |
| 2 | 转播导演自动机位 + 进球多机位回放 | 固定机位为主 |
| 3 | 属性驱动的动作变体（Finishing/Flair 可看见） | 属性不可视 |
| 4 | 半场/赛后战术图版（xG/传球网络/热图） | 简单统计表 |
| 5 | AI 经理决策可解释（字幕/解说讲出"为什么"） | 无此层 |
| 6 | 战术→行为因果链经批测验证（见 03 文档） | 社区报告"可预测、机械" |

## 里程碑内的呈现任务切分

| 阶段 | 呈现层任务 |
|---|---|
| M0 | 无（仿真核期，只做 2D 调试渲染器：能画球员/球/事件标注） |
| M1 | 2D 调试渲染器升级（阵型可视化、逼抢结构可视化——开发工具兼宣传素材） |
| M2 | Unity 3D v1：1 座球场、动画库接入、球-脚同步、广角+追踪双机位、比分条 |
| M3 | 转播导演完整版、图文包装、音频反应引擎、天气渲染、回放系统 |
| M4 | 性能优化、签名动作、夜场灯光、20 队球衣/队徽 |
