## 3. 元素系统（定值内联）

### 3.1 六元素
🔥火（余烬）/💧水（湿润）/🛢油（油渍）/❄冰（霜冻）/⚡雷（充电，zap 天生）/🌿草
（缠绕，aura 天生；樱花草地 26,977 格实测口径）。

### 3.2 附着模型
每敌 6 字段（elem/elemQty/reactT/pendEl/markT+markKind/reactMul）；同种命中 +1.0/发、
DoT+0.3/跳、cap 6.0（共鸣 +1/张）、衰减 0.5/s；个体反应 ICD 0.5s 锚 G.time；引爆
ICD 2.5s 全局单 float（同帧多目标全结算一次）；覆盖即反应+消耗制+pendEl 惰性补结算
（地皮 pending[] cap4）；CONVERT 8×6 表（凝油泼水=解冻；未列忽略；qty clamp）；双
FIFO reactQ+refluxQ(25%)；减速叠加取 min；Elem 写入过 free()。

### 3.3 统一公式

```
反应伤害 = 基准 × (1 + 0.15N) × might × rider × min(reactAmp, AmpCap(n)) × 目标衰减
AmpCap   : R1 1.56 → R5 2.03 → R10 2.78（软帽，超帽部分=当轮鎏金爆发帧，可见）
rider    : 1.5^(轮次-1)，cap ×80 于 R11~12 自然触顶；riderCapRound=13 冻结配置，
           13 轮起停止增长、溢出转 decoration
reactAmp = 1+Σ锅气（回音之爪+0.4/灶王香炉+0.3/引火烧身+0.6/共鸣+0.2×张/雷池+0.8）
不吃：暴击/吸血/投射物数量/穿透/弹速
```

### 10.1 calcMods 管线（L0~L6）

Elem.attach；妈妈全屏斩不消耗九命符。**本条挂 M3a 切片（禁忌卡落地即需）**。
