# 喵都幸存者 Meow Survivors

猫主题幸存者like 小游戏。纯前端 HTML5,无需安装,打开即玩。

## 在线试玩

https://gavin1920.github.io/miaomiao-game/

## 美术

「奶油团子」像素风重制(规范:lab/pixel-remake/STYLE.md,VI 手册:docs/VI手册.html)。
像素素材加载失败时自动回退原版矢量画面,不影响游玩。
