# 猫爪印 · 全武器被动词条 —— 设计案 v4（无限轮次 · 全印无上限）

> 定位：30 级后解锁的「全武器生效」被动词条。**在无限轮次机制下，它是玩家唯一的
> 无限成长轴**：武器/被动满配后，每轮变强全部来自猫爪印。
> 命名：轮次系统已有敌人侧「头目词条」（迅捷/铁壁/狂暴/分裂），玩家侧一律叫
> 「猫爪印」，文档与 UI 不混用"词条"裸词。
>
> v4 变更（用户决策）：**7 枚印全部取消饱和线，无上限叠层**。保留两条引擎级硬底线
> （单武器冷却最低 0.1 秒、场上投射物总量 480）——它们是防死机的技术保护，不属于
> 词条上限。v3 的饱和退出机制整体移除。
> 历史变更：v3 = +贯穿印、武器限选 4 种、批次头目掉宝箱、杂兵极小概率掉宝箱。

## 1. 系统规则总览

| 规则 | 设计 |
| --- | --- |
| 解锁 | `player.lv ≥ 30`（约第 1 轮 11~13 分钟，首个鼠王前见面）。跨轮累计，不清空 |
| 三选一 | 每卡位先掷类别：`P(印卡) = share/(1+share) = 1/3`（share=0.5）；印种类在一次三选一内去重、按 weight 加权抽取；常规卡抽完（满配后）剩余卡位必出印 |
| 精英宝箱 | 奖励位同类别掷签；**无可升级项时：60% 猫爪印 / 40% 金币** |
| 批次头目宝箱 | 每轮 4 次「头目讨伐 → 宝箱 → 变强」：头目被讨伐时原地掉宝箱 |
| 杂兵掉宝箱 | 普通怪死亡 `chestDrop(0.001) + luck × chestLuck(0.0016)` 概率掉宝箱（锦鲤满级约 2.2 倍） |
| 叠层上限 | **全部无上限**。暴击率超过 100% 即必暴击（自然饱和）；冷却/范围等极端值由引擎底线兜底，永不死机 |
| 武器上限 | 除默认猫爪外最多持有 4 种武器；选满后"新武器"卡不再出现 |
| 被动绑定 | 专有被动（进化素材：猫薄荷/小闹钟/小铃铛/弹力毛线/猫爪手套/牛奶盒）**只有拥有对应武器后才进入卡池**；磁铁鱼/幸运锦鲤不绑武器，始终可出。武器选满拿不到新武器后，未解锁的专有被动随之绝迹 |
| 防缓存 | index.html 的 js 引用带 `?v=日期` 版本号；每次改动 js 后更新版本号即可强制所有玩家拿到新文件 |
| 槽位/持久 | 印不占槽位，存 `G.player.affixes`（`{id, stacks}`），resetRun 清空 |

**Run 终点保证**（移除饱和线后依然成立）：吸血在受击结算之后才回复，**单次伤害 ≥
生命上限的一击仍然致死**；敌人伤害轴（dmgK ×1.04~1.13/轮，永不封顶）最终必然产出
这种一击。词条再强也只推迟、不能取消这个终点。

## 2. 七种猫爪印（全部无上限）

| 印 | 颜色 | 每层效果 | 通道 | 模式 | 权重 |
| --- | --- | --- | --- | --- | --- |
| 锐爪印 | 红 | 全武器伤害 ×(1+12%) | `might` | mulUp | 1.0 |
| 疾风印 | 青 | 全武器冷却 ×(1−6%) | `cdMult` | mulDown | 1.0 |
| 广域印 | 绿 | 攻击范围 ×(1+10%) | `areaMult` | mulUp | 1.0 |
| 影分印 | 金 | 投射物 +1（整数，线性） | `amountBonus` | add | 0.7 |
| 贯穿印 | 橙 | 投射物穿透 +1 | `pierceBonus` | add | 0.8 |
| 会心印 | 紫 | 暴击率 +4%（暴伤固定 ×2，>100% 即必暴） | `crit` | add | 1.0 |
| 汲血印 | 粉 | 攻击吸血 +0.4%（按实际伤害回复） | `lifesteal` | add | 1.0 |

- 乘区关系：`伤害 = 基础 ×(1+猫薄荷)×1.12^n`；`冷却 = 基础×小闹钟×0.94^n`（单武器不低于
  引擎底线 0.1s）；`范围 = 基础×弹力毛线×1.10^n`；`数量 = 基础+手套+n`。
- 会心/汲血按加法累积；其余严格乘法；影分因整数语义线性 +1、用 0.7 权重平衡。
- 接入成本：会心/汲血在 `hitEnemy` 单点合并 `opts.crit/lifesteal += mods.*`——光环跳伤、
  猫砂区域、落雷等所有伤害入口自动生效；贯穿在 homing/knife 发射处加 `mods.pierceBonus`
  （斧头 pierce=99 已无限，不动）。

## 3. 武器限选 4 种（不含默认猫爪）

- 猫爪之外最多再选 4 种（场上共 1+4=5 把）；选满后"新武器"卡消失，已选武器升级照常。
- 配置 `slots: { weapon: 4, passive: 6 }`；buildPool 判定"非猫爪武器数 < 4"。
- 收益：8 选 4 构筑决策前置；满配总需求 70 份（第 2~3 轮满配）→ 印更早成为主轴；
  最多 5 次进化。印卡占比恒为 1/3，不随武器池变小而波动（类别模型的优点）。

## 4. 每轮收入预算与成长节奏

- 升级：动态难度目标 5~12 级/轮，取 ~8 → 24 张卡 → 期望 8 张印卡 → 拾取 4~8 层。
- 宝箱：精英 8 + 批次头目 4 + 杂兵随机 2~7 = 14~19 个/轮 ≈ 19~25 个奖励位：
  满配前 ×1/3 ≈ 6~8 层；满配后 60% 出印 → 12~15 层。
- **合计：第 2 轮约 10~12 层，第 3 轮起 16~22 层/轮**，七类均摊 2~3 层/类/轮。
- **无上限下的长期形态**：卡池永远是 7 种，不再有 v3 的"收窄"问题；极端叠层已实测
  （25~30 层）运行稳定——伤害 ×30、冷却 ×0.156（触底 0.1s 引擎底线前）、范围 ×10.8、
  必暴击。数值继续增长只受击杀/开箱速度限制。

## 5. 与动态难度的配合

每轮玩家 DPS 增长（七类均摊 2 层保守口径）≈ **×2.1/轮**。对照：

- 第 2~11 轮：压力轴 ×1.25~1.7/轮（名义 1.45）→ 玩家领先，恒温器吸收盈余；
- 第 12 轮起：杂兵血加法 +1.2/轮（相对 ~+3%）→ 玩家碾压杂兵；威胁只剩密度轴与
  **敌人伤害轴（永不封顶）**。单发 ≥ 生命上限的一击终会出现 → run 有终点；
- DPS 轴：parBossTTK=15s 恒温贴着玩家输出调头目/鼠王血 → 印膨胀不会把 Boss 打成纸。

## 6. 表现设计

- **升级卡**：金色描边 + 「猫爪印」标签，无 pips，显示「已叠 ×N（可无限叠加）」与
  累计倍率（如「全武器冷却 ×0.88 → ×0.83」）。
- **HUD**：被动栏下方一行 24px 印章小图（每种一枚 + ×N 层数），满 10 层金框呼吸。
- **杂兵宝箱**：无横幅，靠宝箱自带金光提示；精英/头目宝箱横幅照旧。
- **暂停/帮助面板**：印总览；帮助面板已写明 30 级解锁、4 武器上限、头目/杂兵宝箱。
- **图标**：7 枚程序绘制印章（圆印泥底 + 白色图形：爪痕/秒表/扩散环/分身/穿环箭/
  四芒星/爱心，红青绿金橙紫粉）。

## 7. 配置表（game_config.js，已实现）

```js
  slots: { weapon: 4, passive: 6 },   // weapon = 猫爪外可选武器数（场上共 1+4 把）

  /* ---------- 猫爪印（玩家侧全武器词条，区别于 rounds.affixes 的头目词条） ---------- */
  stamps: {
    minLevel: 30,      // 解锁等级
    share: 0.5,        // 印卡概率 = 常规卡概率 × share
    chestAffix: 0.6,   // 宝箱无可升级项时出印的概率（其余金币）
    dmg: 0.12, cd: 0.06, area: 0.10,
    amount: 1, pierce: 1, crit: 0.04, lifesteal: 0.004,
    amountWeight: 0.7, pierceWeight: 0.8,
    minCd: 0.10        // 引擎底线：单武器冷却绝对下限（秒），与词条无关
  }
```

```js
  drops: {
    ...,                       // 现有条目不变
    chestDrop: 0.001,          // 普通怪掉宝箱基础概率（约 1/1000 击杀）
    chestLuck: 0.0016          // 幸运每点提高的概率（锦鲤满级 → 约 2.2 倍）
  }
```

## 8. 实现落点（全部已完成）

1. `game_config.js`：slots.weapon=4、stamps 块、drops +chestDrop/chestLuck。
2. `data.js`：STAMP_META/STAMP_ORDER（mulUp/mulDown/add 三种叠层语义 + weightKey）导出。
3. `main.js`：
   - `calcMods()`：被动之后叠印，无任何钳制；产出 `mods.crit/lifesteal/pierceBonus`；
   - `hitEnemy()`：单点合并全局会心/汲血（全武器 + 光环/区域/落雷生效）；
   - 武器接入：homing/knife `pierce + pierceBonus`；orbit 吃 `amountBonus`（碰撞+渲染）；
     aura tick × cdMult（下限 0.15s）；冷却 `max(minCd, base × cdMult)`；
   - `buildPool`/`openLevelUp`：非猫爪计数 <4 才出新武器卡；每卡位掷印类别 + 去重 + 权重；
     常规卡抽完后印卡补位；卡片渲染印分支；
   - `chooseCard`/`openChest`：印叠层分支；宝箱无可升级时 60% 出印；
   - `killEnemy`：batchBoss 掉宝箱；普通怪掉落链末尾杂兵宝箱判定；
   - `drawHUD`：印章 chips 行（×N 角标、满 10 层金框呼吸）；
   - dev 键 `KeyG` 加随机一层；AUTO boss 钩子预置印层。
4. `art.js`：7 枚印章图标；`index.html`：印卡样式（.tag.stamp/.scount）+ 帮助文案；
   `config_panel.js`：stamps/drops 文档与序列化（导出配置完整保留）。

## 9. 验证（全部通过）

- headless 冒烟：16 轮动态难度推演；lv<30 零印卡 / lv31+share 拉满必出印卡；

  20 层数量、暴击 >100% 均按公式持续增长，无钳制）；引擎底线 minCd 存在；
  武器 4 上限（5 把时无新武器卡）；批次头目必掉宝箱；宝箱 60/40 兜底；跨轮不清零；

  渲染正常、击杀正常。
