# 01 · 球员属性系统

## 设计目标

沿用 FM 玩家已经熟悉的心智模型（内部 0-100 存储、界面按惯例折算 1-20 显示；技术/精神/身体三分类、门将专属属性），让英超玩家拿到属性页一眼就懂；但底层与 FM 有本质区别——**每个属性都编译成引擎里的物理参数或决策参数**，直接参与仿真计算，而不是只影响隐藏的概率骰子。

**关键原则：属性页上的每一个数字，都必须能在比赛里"看见"。** 例如盘带 18 的球员过人动作更多、对抗中丢球更少；镇定 6 的球员在禁区里接球会明显更慌（触球偏差变大）。

## 数值换算约定

- **内部存储 0–100 整数**（与 FM 底层实现一致：数据库存 0-100，界面按惯例折算 1-20 显示），所有引擎计算直接使用 0–100。
- UI 显示折算：`display = clamp(round(v / 5), 1, 20)`（95→19，98→20）。
- 引擎内归一化：`x = v / 100 ∈ [0, 1]`。
- 误差类参数：`err = err_min + (1 − x) × (err_max − err_min)`；能力类参数：多为线性或 `x^1.5`（让 95+ 与 85 拉开差距，还原"顶级"的稀缺性）。
- 比赛内属性值先经过**条件修正**（见 §条件修正层），再进入引擎。

## 一、技术属性（Technical，非门将 12 项）

| 属性 | 引擎参数 | 主要生效场景 |
|---|---|---|
| 传中 Crossing | 传中落点高斯误差半径；传中类型（前点/后点/低平）选择质量 | 边路起球、定位球主罚 |
| 盘带 Dribbling | 持球控球半径；被逼抢时控球失败率；变向动作成功率与可用花式库 | 1v1、持球推进、护球 |
| 射门 Finishing | 射门方向误差、力度误差；抢点/捅射类低准备度射门的惩罚系数 | 所有射门 |
| 停球 First Touch | 第一次触球的位移偏差（球停在离脚多远）；高压下偏差放大系数 | 所有接球；接高速球/长传球 |
| 任意球 Free Kick | 直接任意球射门质量、间接任意球传球质量 | 前场定位球 |
| 头球 Heading | 顶球方向误差；争顶成功后的处理质量（攻门/做球/解围分流） | 传中包抄、防守解围 |
| 盯人 Marking | 贴身距离保持误差；漏人概率 | 防守（尤其人盯人任务） |
| 传球 Passing | 传球方向/距离/高度误差（与 Technique、用脚共同决定） | 所有传球 |
| 远射 Long Shots | 18m 以外射门的价值评分加成、精度修正 | 远射决策与执行 |
| 抢断 Tackling | 抢断成功率；铲球时机评估；犯规概率修正 | 逼抢、一对一防守 |
| 技术 Technique | 一脚出球、凌空、倒钩等"高难度动作"的执行乘数 | 高速球处理、华丽动作解锁 |
| （门将）停球 First Touch | 出球体系下的接回传球稳定性 | 门将参与传控 |

> FM 原表里的"角球 Corners / 长边界外球 Long Throws / 点球 Penalties"三项归入**定位球专项**（见 §定位球执行属性），避免属性表过载。

## 二、精神属性（Mental，14 项）

精神属性主要作用于**决策层与防守站位层**，是"AI 显得聪明"的核心来源。

| 属性 | 引擎参数 | 主要生效场景 |
|---|---|---|
| 侵略性 Aggression | 对抗介入频率修正；犯规/吃牌倾向（中性参数，偏高=更多抢断也更多牌） | 全场对抗 |
| 预判 Anticipation | 传球线路拦截半径；对第二落点的反应提前量 | 断球、封堵、抢点 |
| 勇敢 Bravery | 50/50 球投入度；封堵射门/传中的意愿；飞身动作解锁 | 拼抢、堵枪眼 |
| 镇定 Composure | 压力下的执行噪声放大系数（作用于传球/射门/停球的误差项） | 禁区内外所有高压处理 |
| 集中 Concentration | 每 tick"走神"概率（漏人、跟丢跑位者）；随疲劳上升 | 全场，尤其 75 分钟后 |
| 决策 Decisions | 动作效用评分的全局噪声（选错动作的概率） | 每一次持球决策 |
| 意志力 Determination | 落后时的输出衰减抵抗；回追/再压迫意愿 | 比赛末段、落后局面 |
| 才华 Flair | 非常规动作（身后直塞、回做、花式过人）的解锁与权重 | 进攻三区 |
| 领导力 Leadership | 队长光环：全队压力噪声小幅下降 | 指定队长后生效 |
| 无球跑动 Off the Ball | 进攻跑位质量：插上时机、线路选择、盲侧跑 | 所有进攻跑位 |
| 站位 Positioning | 防守基准位误差（防线保持、盯人/区域选择） | 所有防守站位 |
| 团队合作 Teamwork | 自私度修正（该传不传/独走/抢队友球） | 持球决策分流 |
| 视野 Vision | **可见选项集合**（能看到身后与远端的传球线路）+ 长传转移质量 | 出球、直塞、攻防转换 |
| 工作投入 Work Rate | 逼抢覆盖距离、回追完成度、持续输出 | 全场跑动 |

## 三、身体属性（Physical，8 项）

身体属性直接写进运动模型，是 2D/3D 画面上最直观的一层。

| 属性 | 引擎参数 | 主要生效场景 |
|---|---|---|
| 爆发力 Acceleration | 最大加速度 a_max（0→极速的时间） | 启动、变向、逼抢启动 |
| 速度 Pace | 最高速度 v_max（无球冲刺；持球打折，见 §运动模型） | 冲刺、回追、反击 |
| 灵活 Agility | 转向速率上限；小空间动作库 | 盘带变向、小禁区反应 |
| 平衡 Balance | 对抗稳定性；被撞倒概率；身体失衡下的射门/传球修正 | 对抗、护球、禁区处理 |
| 弹跳 Jumping Reach | 争顶有效高度（与时机加成合成对抗值） | 空中对决 |
| 体质 Natural Fitness | 疲劳曲线形状 + 中场恢复率 | 全场衰减 |
| 耐力 Stamina | 疲劳消耗系数 | 全场衰减 |
| 力量 Strength | 肩部对抗强度；护球牢固度；抢断对抗加成 | 身体对抗、背身拿球 |

## 四、门将专属属性（GK，12 项）

| 属性 | 引擎参数 |
|---|---|
| 制空范围 Aerial Reach | 出击摘传中的有效半径 |
| 指挥禁区 Command of Area | 摘传中成功率；后卫让球给的信心阈值 |
| 沟通 Communication | 指挥防线协同（防线保持误差↓）；避免与后卫撞车概率 |
| 手型 Handling | 扑救脱手概率（接住/脱手/扑出三态分流）；雨天惩罚 |
| 开大脚 Kicking | 球门球/手抛球长传精度与距离 |
| 单刀 One on Ones | 一对一封堵角度效率、出击时机 |
| 反应 Reflexes | 近距离反应扑救成功率（<12m 快速射门） |
| 拳击倾向 Punching | 倾向参数：处理传中时拳击 vs 接球的选择权重 |
| 出击倾向 Rushing Out | 倾向参数：身后球出击阈值（配合清球门将角色） |
| 神经刀 Eccentricity | 低频重大失误概率（脱手/站位离谱）——低=好 |
| 手抛球 Throwing | 快速反击手抛球精度 |
| 停球 First Touch | 传控体系下的接回传球稳定性（按出球门将要求） |

门将同样有精神/身体属性，其中 镇定（高压扑救）、集中（走神=失球）、站位 Positioning（扑救预站位）、反应类身体属性 权重最高（见 §CA 权重）。

## 五、定位球执行属性（专项）

| 属性 | 说明 |
|---|---|
| 角球 Corners | 角球落点质量（前/后/近门柱选择 + 落点误差） |
| 点球 Penalties | 点球命中率；压力修正（由 Composure 再放大） |
| 长边界外球 Long Throws | 长掷界外球距离与精度（拥有该属性的球员解锁"手榴弹"战术选项） |

## 六、隐藏属性（对玩家不可见，引擎可见）

| 属性 | 引擎效果 |
|---|---|
| 稳定性 Consistency | 单场表现方差：决定属性值每场的随机浮动幅度（稳定性 1 = 神经刀，20 = 场场 90% 水准） |
| 大赛发挥 Important Matches | 关键比赛（德比/强强对话/决赛）时的属性乘数 |
| 伤病倾向 Injury Proneness | 训练/比赛受伤概率；AI 经理换人决策的输入之一 |
| 多面性 Versatility | 位置熟悉度的成长速度与惩罚减免 |
| 小动作 Dirtiness | 隐蔽犯规概率（裁判发现概率独立计算） |
| 性格簇 Professionalism/Ambition/Pressure/性格 等 | 比赛日版本仅保留士气耦合（压力性格 → 落后时 Composure 惩罚）；其余留给未来生涯模式 |

## 七、CA / PA 与位置权重

- **CA（当前能力）**：1–200 的总评，由各属性按**位置权重**加权求和得出。同一名球员换位置，CA 不变，但**有效表现**会因位置权重变化而变化——这两层必须分开。
- **PA（潜力）**：比赛日版本仅用于 UI 展示与 AI 经理的轮换逻辑，不参与计算。
- 位置权重表示例（示意，实际值在 M0 校准）：

| 位置 | 高权重属性（示例） |
|---|---|
| ST | Finishing, Off the Ball, Composure, Pace, Acceleration, First Touch |
| W | Dribbling, Acceleration, Pace, Crossing, Flair, Agility |
| AMC/AP | Vision, Passing, Decisions, Off the Ball, Technique |
| MC/B2B | Stamina, Work Rate, Teamwork, Passing, Positioning, Tackling |
| DM/DLP | Positioning, Passing, Decisions, Concentration, Tackling |
| DC | Positioning, Marking, Tackling, Heading, Jumping, Strength |
| FB/WB | Stamina, Work Rate, Positioning, Crossing, Pace |
| GK | Reflexes, Handling, Positioning, Concentration, Command of Area |

## 八、位置与角色熟悉度

- 位置网格沿用 FM：GK / D(R,L,C) / WB(R,L) / DM / M(R,L,C) / AM(R,L,C) / ST。
- 每名球员每位置一档熟悉度，3 档：**自然(×1.00) / 熟练(×0.92) / 生疏(×0.80)**；门将位不兼容时禁用（×0.60 上限）。
- 位置修正作用于：防守站位误差、跑位时机、以及全属性有效值的小幅折损。
- **角色熟悉度**：战术系统里每名球员对"被安排的角色"（如 拖后组织核心）也有熟悉度，首次担任=低，随比赛场次提升（详见 02 文档 §战术熟练度）。

## 九、条件修正层（比赛内生效）

| 修正项 | 来源 | 引擎效果 |
|---|---|---|
| 疲劳 Fatigue | 比赛内实时计算（跑动强度×位置） | 作用 v_max、a_max、Concentration、误差率（详见 03 文档 §疲劳） |
| 士气 Morale | 近期战绩 + 比赛内事件（进球/丢球/扑救） | 5 档，作用于风险偏好与误差率 ±5% |
| 状态 Form | 近 5 场滚动表现 | 简化为 ±1 属性点浮动 |
| 锐度 Sharpness | 比赛日版本为常量 100% | 留给未来赛季模式 |

## 十、惯用脚与球员特性（Traits / PPMs）

- **惯用脚**：左右脚各 1–20。引擎里决定用脚选择（逆足侧传球/射门误差 ×1.3–1.6），直接影响内锋逆足内切打门的价值——FM 战术的重要一环。
- **球员特性**（自选标签，每球员 0–3 个）：直接覆盖决策权重，是"个体感"的最便宜来源。首发清单：

| 特性 | 引擎钩子 |
|---|---|
| 喜欢远射 | 远射动作权重 ×1.5 |
| 爱盘带过人 | 盘带动作权重 ×1.4 |
| 喜欢直塞身后 | 直塞权重 ×1.5 |
| 回做型 | 停球后回传/横传权重 ×1.3 |
| 喜欢抢点近门柱 | 传中包抄目标点偏好 |
| 高举高打 | 传中倾向 ↑（若为传中型角色） |
| 喜欢利用速度 | 身后跑权重 ×1.4 |
| 拉边型前腰 | 锚点横向偏移 |
| 喜欢内切 | 边路角色锚点内收 + 内切动作解锁 |
| 贴地传中 | 传中类型偏好低平球 |
| 犯规战术型 | 战术性犯规意愿（AI 经理会用于保护领先） |
| 大力手抛球 | 解锁手榴弹界外球战术 |

## 十一、数据 Schema 与生产

**存储格式：CSV（UTF-8），一队一文件** —— `data/players/{club_id}.csv`，共 63 列（完整列定义与记法见 [data/README.md](../data/README.md)）：

- 元信息 9 列：`id, name, club, age, height_cm, weight_kg, foot_l, foot_r, positions`
- 技术属性 11 列 + 定位球 3 列 + 精神属性 14 列 + 身体属性 8 列 + 门将属性 12 列 + 隐藏属性 5 列 + `traits`
- 所有属性列取值 **0–100**（见 §数值换算约定）；门将行填写门将列、技术列仅填 `first_touch/passing`；非门将行门将列留空。
- positions 记法：`ST*`=自然 / `ST+`=熟练 / `ST`=生疏；`foot_l/foot_r` 为左右脚 0–100。

- 规模 v0：20 队一线队，每队约 17–25 人（首发 11 人精细标定，替补/轮换粗标定）。
- 生产方式 v0：参照公开数据源与社区评测人工标定（已完成，数据版本基准见 data/README.md）；v1 脚本批量生成再人工修整；发布版整体替换为化名。
- 身高体重必须真实录入：进运动模型（争顶高度、对抗惯性、转身半径）。
- 数据校验：`python scripts/validate_data.py`（列数/取值范围/位置合法/门将列完整性/traits 词表）。
