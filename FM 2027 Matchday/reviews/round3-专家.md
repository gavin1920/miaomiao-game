## 2. 双轴门槛正式版判定：**FAIL（第二轮）**

- **attPush6 GA 差 = +0.00**（门槛 ≥+0.15）。def 税 `max(0,pushF-1)*4.5` 只值 ~1.7 def 分 ≈ 对方 pChance +3%，完全埋没在噪声里。实施方自报「攻压6 GA差 +0.32 ✓」以我的配对口径**不可复现**。
- **defBlock 双向 ≈ 0：防守半轴是死的。** 根因（代码级）：`def += clamp((2.6-blockF)*3.4, 0, 7.5)`（engine.js:212）——该式对 blockF **递减**：极不设防(0) +6.97、均衡(3) +5.44、铁桶(6) +4.15，**方向接反**；而 defBlock 同时把 lineX 压低 `(defBlock-3)*1.2`，深线少挨反击 → 两条通道相互抵消，净效应归零。实施方自报「防稳6 GD +0.08~0.18 ✓」我复测为 **+0.020±0.09，不可复现**。
- 大巴未转正：BUR 双轴大巴（att0/block6/5-4-1/counter）vs MCI **7.2% 胜/26.4% 不败**，比 BUR 官方（19.6%/41.6%）**更差**。
- 处方（下轮 3 行改动）：①blockF 项改正斜率 `def += (blockF-1)*6`；②blockF 真进对方 pChance（如 ×(1.15-blockF*0.05)）；③attPush 税 4.5→10~12。
